# 프린터 설정 가이드 (서버 PC — 필독)

이 도구는 **서버 PC에 등록된 프린터 이름**으로 인쇄를 보냅니다.
정상 작동을 위해 서버 PC에서 아래 프린터 설정을 먼저 완료해 주세요.

## 1. 프린터 수동 추가

1. Windows **[설정] → [블루투스 및 장치] → [프린터 및 스캐너]** 이동
2. **[장치 추가]** 버튼 클릭 후 대기
3. **[원하는 프린터가 목록에 없습니다]** 옆의 **[수동으로 추가]** 클릭

## 2. IP 주소를 이용한 연결

1. **[TCP/IP 주소 또는 호스트 이름으로 프린터 추가]** 선택 후 [다음]
2. 장치 유형: **[TCP/IP 장치]** 선택
3. 호스트 이름 또는 IP 주소: 프린터의 고정 IP 입력 (예: `192.168.0.100`)
4. **[포트에 쿼리하여 사용할 프린터 드라이버를 자동으로 선택]** 체크 확인 후 [다음]

## 3. 프린터 이름 식별 (권장)

설치 마지막 단계에서 프린터 이름을 구분하기 쉽게 바꿔두면 편합니다.

```
본문용_A3_프린터
답지용_A4_프린터
```

웹 화면의 **'본문 (A3) 프린터' / '답지 (A4) 프린터'** 선택 상자에서
이 이름들을 선택하면 됩니다.

## 주의사항

- 서버 PC에 **한컴오피스 한글이 반드시 설치**되어 있어야 합니다.
- 인쇄 중에는 서버 PC의 한글 프로그램이나 인쇄 창을 강제로 닫지 마세요.
