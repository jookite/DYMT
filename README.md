# 📄 강다영수학 프린트 도우미 — 한글(HWP) 본문/답지 분할 인쇄 서버

한글(HWP) 문서의 **첫 번째 미주(Endnote)** 를 자동으로 찾아, 그 페이지를 기준으로
**본문(A3)** 과 **답지(A4)** 를 서로 다른 프린터로 한 번에 분할 인쇄하는 도구입니다.

웹 기반이라 **프린터가 연결된 Windows PC 한 대만 서버로 켜두면**,
같은 네트워크의 누구나(윈도우·맥·폰) 브라우저로 접속해 사용할 수 있습니다.

```mermaid
flowchart LR
    A["👩‍💻 사용자 A<br/>(브라우저)"] -->|파일 업로드| S
    B["👨‍💻 사용자 B<br/>(맥북 브라우저)"] -->|파일 업로드| S
    S["🖥️ 인쇄 서버 PC<br/>HWP_print_web.py<br/>+ 한컴오피스 한글"] -->|본문| P1["🖨️ A3 프린터"]
    S -->|답지| P2["🖨️ A4 프린터"]
```

## 주요 기능

- **다중 파일 업로드** — .hwp / .hwpx 여러 개를 한 번에 올리고, 파일별로 설정
- **파일별 분할/전체 모드** — 분할 ON: 첫 미주 기준으로 본문·답지를 나눠 각각 다른
  프린터로 / 분할 OFF: 전체를 양쪽 프린터로 통째로 인쇄
- **파일별 부수 지정** — 본문·답지 부수를 각각 지정 (0부 입력 시 해당 쪽은 건너뜀)
- **다중 사용자 대기열** — 여러 명이 동시에 접속해도 각자 자기 파일 목록만 보이며,
  인쇄 작업은 공용 대기열에 쌓여 순서대로 처리
- **실시간 공유 로그** — 누가 무엇을 몇 부 보냈는지, 진행 상황을 전원이 실시간 확인
- **자동 정리** — 인쇄가 끝난 업로드 파일은 서버에서 자동 삭제

## 요구 사항 (서버 PC)

| 항목 | 내용 |
|---|---|
| OS | Windows (한글 COM 자동화가 Windows 전용) |
| 프로그램 | 한컴오피스 한글(HWP) 설치 필수 |
| Python | 3.10 이상 권장 |
| 프린터 | 본문용(A3)·답지용(A4) 프린터 연결 — [프린터 설정 가이드](docs/프린터_설정_가이드.md) |

접속하는 쪽(사용자)은 **브라우저만 있으면 됩니다.** 맥북·스마트폰도 가능합니다.

## 설치

```bash
git clone https://github.com/jookite/DYMT.git
cd DYMT
pip install -r requirements.txt
```

## 실행

```bash
python HWP_print_web.py
```

또는 **`인쇄서버_시작.bat` 더블클릭.**

- 첫 실행 시 Windows 방화벽 팝업이 뜨면 **"허용"** 을 눌러야 다른 기기에서 접속됩니다.
- 실행하면 서버 PC에서는 브라우저가 자동으로 열리고, 화면 상단에
  `http://<서버IP>:58021` 형태의 **공유용 접속 주소**가 표시됩니다.

## 사용 방법

1. 브라우저로 접속 후 **이름**을 입력합니다 (공유 로그에 표시됨).
2. **본문(A3) / 답지(A4) 프린터**를 선택합니다.
3. 한글 파일을 **여러 개 업로드**하거나, **"폴더째로 업로드"** 로 폴더 안의
   한글 파일을 한 번에 올립니다.
4. 파일별로 **분할 여부**와 **본문·답지 부수**를 입력합니다.
   (전부 1부씩이면 **"모두 1부"** 버튼)
5. **인쇄 시작** — 작업이 공용 대기열에 들어가고 순서대로 인쇄됩니다.

> ⚠️ 분할 모드인데 문서에 미주가 없으면 해당 파일은 인쇄하지 않고 건너뜁니다.
> 그런 파일은 '분할' 스위치를 끄면 전체 인쇄됩니다.

## 공용 PC 배포 (exe — Python 설치 불필요)

Python이 없는 PC를 서버로 쓰려면 exe로 빌드해서 복사하면 됩니다.

```bash
pip install pyinstaller
nicegui-pack --onefile --name "강다영수학_프린트도우미" HWP_print_web.py
```

`dist/` 폴더에 생성된 exe를 서버로 쓸 PC에 복사한 뒤:

1. 그 PC에 **한컴오피스 한글**이 설치되어 있는지 확인
2. [프린터 설정](docs/프린터_설정_가이드.md) 완료
3. exe 실행 → 방화벽 팝업 **"허용"**
4. 상시 운영하려면 `Win + R` → `shell:startup` 폴더에 exe 바로가기 추가
   (PC가 켜질 때마다 자동 실행)
5. 전원 설정에서 **절전 모드 해제** (절전에 들어가면 접속이 끊깁니다)

## 서버 운영 팁

- **상시 운영**: `Win + R` → `shell:startup` 폴더에 `인쇄서버_시작.bat` 바로가기를
  넣으면 PC 부팅 시 자동 시작됩니다.
- **고정 IP**: 공유기 DHCP 설정에서 서버 PC에 고정 IP를 지정해두면 접속 주소가
  바뀌지 않습니다.
- **네트워크 범위**: 사내망(같은 공유기) 전용입니다. **인터넷에 직접 공개하지 마세요.**
- **한글 팝업**: 한글 보안/오류 팝업은 서버 PC 화면에 뜨므로, 인쇄가 멈춘 것 같으면
  서버 화면을 확인하세요.

## Lab 연동 (관리자 페이지에서 바로 인쇄)

Lab(`https://app.dayoungmathclass.com`)의 **프린트 도우미** 메뉴는 이 프로그램이
실행 중인 PC에서 열면 자동으로 연결됩니다 (`http://127.0.0.1:58021`의 `/api/*`).

- **오답노트 다운로드** 페이지의 `🖨️ 인쇄` 버튼 — ZIP을 내려받거나 압축을 풀
  필요 없이, 서버의 오답노트 묶음이 그대로 이 프로그램으로 전달되어 학생
  이름순으로 분할 인쇄됩니다.
- **프린트 도우미** 페이지 — 파일/폴더 업로드, 파일별 분할·부수·`~번까지`
  옵션, 실시간 진행 로그, 취소.
- 보안: 허용된 출처(`ALLOWED_ORIGINS`)의 브라우저 요청만 받습니다. 브라우저가
  "로컬 네트워크 접속 허용" 팝업을 띄우면 **허용**을 눌러야 합니다.

### 로컬 API 요약

| 창구 | 내용 |
|---|---|
| `GET /api/health` | 연결 확인 (버전·상태·대기 수) |
| `GET /api/printers` | 프린터 목록과 기본 프린터 |
| `POST /api/jobs` | 파일들 + 파일별 옵션(items JSON) 접수 → `job_id` |
| `POST /api/jobs/zip` | ZIP 하나를 공통 옵션으로 접수 (오답노트용) |
| `GET /api/jobs/{id}` | 상태·파일별 결과·증분 로그 (`?since_log=N`) |
| `POST /api/jobs/{id}/cancel` | 취소 요청 |

모든 접수 창구는 `dry_run=1`(검사 모드 — 분할 계산만 하고 인쇄 안 함)을
지원합니다.

```
├─ docs/

   ├─ HWP_print_tool.py      #   v2: 파일 목록 + 폴더 일괄 (탭 UI)

```
